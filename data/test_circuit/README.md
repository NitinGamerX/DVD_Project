# Test circuit SPICE reference (Part C, step 6)

Generated by `scripts/06_cla_spice.py` (`make cla-spice`). Evaluation data only.

`spice_cla3.csv`: one row per input combination and corner (128 × 200 = 25,600 rows), the
whole 3-bit CLA simulated as one transistor-level netlist (`netlists/test_circuit/cla3.cir`).

| Column | Meaning |
|--------|---------|
| `inputs` | input bits as text in the order a0 a1 a2 b0 b1 b2 cin (read it as text: leading zeros) |
| `A`, `B`, `cin` | the operands (A = a2a1a0, B = b2b1b0) and the carry-in |
| `corner`, `vdd`, `temp` | the corner, same 200 as the gates (`data/gates/corners.csv`) |
| `leak_total` | A, current delivered by every source at VDD: supply + inputs at logic 1 |
| `leak_vdd` | A, current delivered by the VDD supply alone |
| `i_vdd`, `i_a0` … `i_cin` | raw ngspice source branch currents (negative = source delivers) |
| `v_s0` … `v_c3` | adder outputs (V) |
| `max_net_offset_mV`, `worst_net` | largest distance of any cell output from its logic rail, and which net |
| `nets_off_logic` | cell outputs more than 5 % of VDD from their rail (0 everywhere when the check passes) |

Circuit: `src/dvd/cla.py` (39 cells: 24 NAND2 forming 6 XORs, 9 AND2, 6 OR2; 186 transistors).
