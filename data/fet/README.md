## Columns (exactly as listed in section 6 of the project document)

| Column | Unit | Meaning |
|--------|------|---------|
| `vdd` | V | supply for this sample, nominal 1.0 V ± 10 % (drawn first) |
| `temp` | °C | −40 to 125 |
| `w` | m | channel width, 1–8 × Lmin (22–176 nm); L = 22 nm fixed |
| `vd`, `vs` | V | drain and source voltage, each uniform in [0, VDD] |
| `vg`, `vb` | V | gate and body voltage, fixed by the case (0 or VDD) |
| `vth0`, `toxe`, `ndep`, `u0`, `xj` | V, m, cm⁻³, m²/(V·s), m | process parameters of this device's type, nominal ± 10 % |
| `id`, `ig`, `is`, `ib` | A | terminal currents |

Source/drain geometry is not a column because it is a fixed function of W:
AS = AD = W · 44 nm, PS = PD = 2(W + 44 nm).

## Sign convention

Currents are ngspice source branch currents I(Vd), I(Vg), I(Vs), I(Vb), the convention
of the example netlist and of the sample database in the lecture slides:
**positive = current flowing out of the device terminal into its voltage source.**
The current flowing *into* the device at a terminal is the negative of the column.
The four columns sum to zero up to solver tolerance (Kirchhoff check, Phase 2).

## Numerical resolution (measured, `results/data_check/numerical_resolution.csv`)

Double-precision rounding inside the solver leaves a small absolute noise on each current.
It matters only where a current is itself tiny:

| Case | Id, Is | Ig | Ib | Ib below 1e-15 A |
|------|--------|----|----|------------------|
| NMOS ON  | ~5e-17 A | ~9e-16 A | ~1e-20 A | 0 % |
| NMOS OFF | ~6e-20 A | ~1e-20 A | ~2e-22 A | 72 % (real, resolved values) |
| PMOS ON  | ~2e-17 A | ~8e-20 A | ~2e-17 A | 0 % |
| PMOS OFF | ~3e-20 A | ~7e-15 A | ~2e-17 A | 71 %, 456 exact zeros |

The PMOS OFF body current is the one quantity that is mostly noise: with the body at VDD
its value is resolved only in steps of about 3.5e-18 A, so PMOS OFF `ib` values below
~1e-16 A carry no information. Every other current is resolved far below its smallest value.
Phase 3 must therefore score `ib` against a floor rather than by plain relative error.
