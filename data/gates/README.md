# Gate SPICE reference (Part B, step 3)

Generated by `scripts/04_gate_spice.py` (`make gates-spice`). Evaluation data only: never
used for training. Re-running reproduces the files exactly (fixed seed).

## `corners.csv` — the 200 corners (also used for the test circuit in Part C)

| Column | Meaning |
|--------|---------|
| `corner` | corner index 0–199 |
| `vdd`, `temp` | supply (V, nominal 1.0 V ± 10 %) and temperature (°C, −40 to 125) |
| `vth0_n` … `xj_n` | process parameters shared by every NMOS in the circuit (nominal ± 10 %) |
| `vth0_p` … `xj_p` | process parameters shared by every PMOS in the circuit (nominal ± 10 %) |

## `spice_gates.csv` — one row per gate, input combination and corner (18 × 200 = 3600 rows)

| Column | Meaning |
|--------|---------|
| `gate`, `inputs` | inv / nand2 / nor2 / and2 / or2; input bits as text (`"0"`, `"01"`; A first) |
| `corner`, `vdd`, `temp` | the corner (process values: join on `corner` with `corners.csv`) |
| `leak_total` | A, current delivered by every source at VDD: supply plus inputs at logic 1 (= static power / VDD) |
| `leak_vdd` | A, current delivered by the VDD supply alone |
| `i_vdd`, `i_a`, `i_b` | A, raw ngspice source branch currents (negative = the source delivers current) |
| `v_out` | V, output |
| `v_x`, `v_y` | V, internal stack node (x: NAND2/AND2 pull-down, y: NOR2/OR2 pull-up); empty where absent |
| `v_nand_out`, `v_nor_out` | V, internal NAND2/NOR2 output inside AND2/OR2; empty where absent |

Which leakage definition the course intends is open question D2 in `DECISIONS.md`;
both are recorded. They differ most where inputs held high drive gate tunnelling
current into NMOS gates (NOR2 at AB = 11: 14× in the median).

## Circuits

Transistor lists: `src/dvd/gates.py`; netlists for corner 0: `netlists/gates/<gate>.cir`
(run from that folder with `ngspice -b <gate>.cir`). Widths (W_n / W_p): INV 44/88 nm,
NAND2 88/88 nm, NOR2 44/176 nm; L = 22 nm; source/drain areas as in Phase 1.
